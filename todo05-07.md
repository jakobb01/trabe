Target: a combined 0.7.0 release ready to deploy, retaining the existing Pi
installation, private Telegram interface, portfolio and price monitoring.
Do not deploy or start another real Telegram poller during this implementation.

## Common contracts (root agent owns shared files)

- [x] Add `trabe/signals.py`, schema version 5 and bounded signal storage. Preserve
  0.4 transactions, historical FX, preferences, quotes and reply queues.
- [x] `SignalStore(store)` exposes:
  - `put(kind, key, symbol, source, payload, *, now, event_time=0, available_at=0)`;
    upsert a stable event and return its previous row or `None`.
  - `get(kind, key)` and `rows(kind, symbols=None, *, limit=100, since=0)`; rows
    contain `kind,key,symbol,source,payload,event_time,available_at,observed_at`.
  - `due(kind, source, symbol, interval, now)`, `attempt(...)`, `ok(...)`,
    `fail(kind, source, symbol, error, now, retry=3600)` for persisted source state.
  - `notify_once(owner_id, kind, key, text, *, now, setting)` atomically claims
    a notification and enqueues it, rechecking pause and feature enablement.
- [x] `SignalHTTP(config, store, *, stop=None, automatic=False, feature=None)`
  exposes `finnhub(endpoint, **params)` for JSON objects/arrays,
  `alpha_csv(function, **params)` and `json(url, provider=...)` / `xml(url,
  provider=...)` for approved public feed hosts. All responses and timeouts are
  bounded; errors never expose keys or response bodies.
- [x] Share Finnhub's file lock, pacing, cooldown and persisted budget with price
  requests; share Alpha's existing budget/pacing. Fundamentals are independent of
  `/monitor on` and selected price provider. Automatic work always respects
  global pause, storage state, feature switches and shutdown before each call.
- [x] Bound Tracefour to its documented rolling-hour allowance and persist
  public-provider cooldowns. Keep HTTP work outside SQLite write transactions.
- [x] Store event time, publication/availability time and first observation time
  separately. Keep compact signals for three calendar months with global row caps;
  never collect article bodies or a second tick archive.

## Feature contracts and separate coding ownership

Feature classes receive `(store, http)` and use `SignalStore`. Their methods are:
`refresh(symbols, *, now, force=False)`, `report(symbols, *, now)`,
`alerts(symbols, *, now)` returning `(claim_key, text)` pairs, and
`briefing(symbols, *, now, limit=3)` returning short text lines.
Feature `refresh` handles per-symbol caching, sanitized source status and fallback;
it does not send Telegram messages. Root integrates scheduling and atomic claims.
`News.alerts` may return no items: news is delivered on demand or in briefings.
